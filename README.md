# Thiranex Task 4 — Asynchronous JavaScript & RESTful APIs

A responsive real-time weather dashboard built with HTML5, CSS3 and Vanilla JavaScript.

## Features
- Fetches city coordinates from the Open-Meteo Geocoding REST API
- Fetches live weather data using `fetch()` and `async/await`
- Displays temperature, humidity, wind speed and feels-like temperature
- Search weather by city
- Handles failed requests and unknown cities
- Responsive layout for mobile and desktop
- No API key required

## Technologies
HTML5 • CSS3 • JavaScript • Fetch API • REST APIs • Async/Await

## Run
Open `index.html` in a browser. For best results, use a local development server such as VS Code Live Server.
